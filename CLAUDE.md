# CLAUDE.md

Инструкции для Claude Code по работе с этим репозиторием.

## MCP: MarkItDown (PDF → Markdown)

В проекте подключён MCP-сервер **MarkItDown** от Microsoft
([microsoft/markitdown](https://github.com/microsoft/markitdown)). Он превращает
PDF и другие документы в Markdown.

### Конфигурация

Сервер зарегистрирован в `.mcp.json` в корне репозитория и запускается через `uvx`
по STDIO-транспорту (отдельная установка не нужна — `uvx` подтягивает пакет
`markitdown-mcp` при первом запуске):

```json
{
  "mcpServers": {
    "markitdown": {
      "command": "uvx",
      "args": ["--from", "markitdown-mcp", "markitdown-mcp"]
    }
  }
}
```

При первом запуске Claude Code спросит подтверждение на использование MCP-сервера
из `.mcp.json` — его нужно одобрить. Проверить статус можно командой `/mcp` в
интерактивной сессии.

### Доступный инструмент

Сервер предоставляет один инструмент:

- **`convert_to_markdown`** — принимает URI и возвращает содержимое в Markdown.
  Поддерживаемые схемы URI:
  - `file:` — локальный файл, например `file:///home/user/hello_world/doc.pdf`
  - `http:` / `https:` — документ по ссылке
  - `data:` — data-URI со встроенным содержимым

### Как конвертировать PDF в Markdown

1. Определи абсолютный путь к PDF-файлу.
2. Вызови инструмент `convert_to_markdown` с URI вида
   `file:///абсолютный/путь/к/файлу.pdf` (три слэша + абсолютный путь).
3. Сохрани результат в `.md`-файл рядом с исходником (то же имя, расширение `.md`),
   если пользователь не указал другое расположение.

Пример URI для файла в этом проекте:

```
file:///home/user/hello_world/example.pdf
```

### Заметки и ограничения

- Помимо PDF, MarkItDown умеет конвертировать Word, PowerPoint, Excel, HTML,
  изображения, аудио и другие форматы — тот же инструмент `convert_to_markdown`.
- Для локальных файлов всегда используй **абсолютный** путь в `file://` URI.
- Для распознавания речи из аудио требуется `ffmpeg` (для PDF не нужен).
- Извлекается текстовое содержимое; сложная вёрстка и точное позиционирование
  элементов страницы могут не сохраниться.
